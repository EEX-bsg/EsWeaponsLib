# はじめに(プレイヤー向け)

E'sWeaponsLib(EWL)は、武装 Mod が使う**前提 Mod** です。EWL だけを入れてもブロックは増えません。
EWL を使う Mod(E'sTankCannonsMod など)を遊ぶときに一緒に入れてください。

## 導入

1. Steam Workshop で EWL を購読する(公開後)。
2. EWL を使う Mod を購読する。
3. Besiege を起動する。

EWL はタイトル画面の時点で読み込まれます。そのため、**EWL を無効にしたり有効にしたりしたときは、Besiege の再起動が必要**です。

## マルチプレイ

- ホストと参加者で、同じ Mod(EWL を含む)を入れてください。
- EWL の武装は自動で同期されます。途中参加した人には、参加する前に撃たれた弾は見えません(次の弾から見えます)。

## 困ったとき

| 症状 | 確認すること |
|---|---|
| ブロックが撃てない・機能しない | EWL が有効か。EWL を有効にした後に Besiege を再起動したか |
| ブロックの一部の機能だけが無い | EWL と、そのブロックの Mod の両方が最新か |
| マルチプレイで弾が見えない・ずれる | 全員が同じ版の Mod を入れているか |

それでも直らないときは、`Besiege_Data/output_log.txt` の `[EWL]` で始まる行を添えて、ブロックの Mod の作者か EWL の Issue に報告してください。
