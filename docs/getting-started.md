# はじめに(プレイヤー向け)

E'sWeaponsLib(EWL)は、武装Modが使う**前提Mod** です。EWLだけを入れてもブロックは増えません。
EWLを使うMod(E'sTankCannonsModなど)を遊ぶときに一緒に入れてください。

## 導入

1. Steam WorkshopでEWLとそれを使うMod(E'sTankCannonsMod等)をサブスクライブする。
2. Besiegeを起動する。
3. Modメニューを開き、双方を有効化する。

## マルチプレイ

- ホストと参加者で、同じMod(EWLを含む)を入れてください。
- EWLの武装は自動で同期されます。途中参加した人には、参加する前に撃たれた弾は見えません(次の弾から見えます)。

## 困ったとき

| 症状 | 確認すること |
|---|---|
| EWLが機能しない | EWLが有効か。EWLを有効にした後にBesiegeを再起動したか |
| EWLの一部の機能だけが無い | EWLと、その利用Modの両方が最新か |
| マルチプレイで同期がズレる | 全員が同じ版のModを入れているか |

まずはBesiegeの再起動を推奨します。  
それでも直らないときは、`Besiege_Data/output_log.txt` を添えて、EWL利用Modの作者かEWLのIssueに報告してください。
