# 誘導ミサイル

EWLの誘導弾がどう目標を決め、どう飛ぶかの説明です。

> [!WARNING]
> 誘導は開発中の機能です。目標の決まり方・飛び方・要素・係数は、今後大きく変わることがあります。
> 誘導を使うModを作る前に、制作者に現状を確認してください。変えたときは [CHANGELOG](https://github.com/EEX-bsg/EsWeaponsLib/blob/main/CHANGELOG.md) に書きます。

## 使い方

誘導は弾の向き(機首)を回すだけです。前へ進む力は推進(`Booster`)が出すので、組み合わせて使います。

```xml
<Projectile>
    <Drag>0.9</Drag>                    <!-- 抗力。推力と釣り合う速さで頭打ちになる -->
    <AngularDrag>15</AngularDrag>       <!-- 回転の抵抗。向き直るときの振動を抑える -->
    <IgnoreGravity>true</IgnoreGravity>
    <Booster>
        <Thrust>1000</Thrust>           <!-- 推力 [N] -->
        <Stability>0.5</Stability>      <!-- 安定翼 -->
        <MaxSpeed>220</MaxSpeed>        <!-- 最高速度 [m/s] -->
    </Booster>
    <Guidance>
        <Gain>0.25</Gain>               <!-- 誘導の強さ -->
        <ReleaseAngle>90</ReleaseAngle> <!-- 機首と目標方向の角がこれを超えたら誘導をやめる [度] -->
    </Guidance>
</Projectile>
```

**目標はXMLだけでは決まりません。** C#で `Weapon.Target` に目標を入れます。照準をどう作るか(カメラの画面中心など)は、あなたのModが決めます。

```csharp
// 撃つ人のピアで毎フレーム
var view = myCamera.transform;
_weapon.Target = _weapon.FindTarget(view.position, view.forward, 6f);
```

手順と注意は [C#で使う](csharp.md#誘導の目標を指定する) にあります。

## 目標

| 項目 | 内容 |
|---|---|
| 目標になれるもの | 敵マシンのコアブロック。敵 = 自分のマシン以外で、観戦中でなく、グローバルシミュレーション中のプレイヤーのマシン。撃つブロックにチームがあれば同じチームは除く(チーム無しは全員が敵) |
| 探し方 | `Weapon.FindTarget` は、照準の向きから指定角以内の敵のうち、照準の中心に最も近い(角度が最も小さい)ものを返す。距離では選ばない |
| 確定 | `TryFire` が発射を受け付けた時点の `Weapon.Target` で確定する。発射遅延・バーストで後から出る弾も同じ目標を追う |
| 確定の後 | 飛んでいる弾の目標は変わらない。`Target` を後から変えても、発射待ち・飛行中の弾には効かない |
| 無効な目標 | 確定の時点で有効な敵のコアでなければ(味方・壊れた・リスポーンした・任意の物体など)、その弾は無誘導 |
| マルチプレイ | 撃つブロックの持ち主のピアで指定する。持ち主がクライアントなら、EWLがホストへ送る。ホストは持ち主以外からの指定と、敵のコアでない指定を受け付けない |
| SP・ローカルシミュレーション | 他のプレイヤーがいないので、目標は見つからない(確認には後述のテスト用標的を使う) |

## 飛び方

| 段階 | 動き |
|---|---|
| 発射から0.2秒 | 発射方向を保つ(目標の有無に関係なく) |
| 追尾 | 機首を迎撃点の方へ回す(下記) |
| 無誘導 | 向きを保って直進する。目標なしで撃った弾は発射方向、目標を失った弾はその時点の向き。発射方向へ戻ることはない |

どの段階でも、推進・安定翼・抗力・重力・寿命・時限信管はそれぞれの設定どおりに働きます。

### 追尾中の操舵

1. **迎撃点を予測する。** 目標が弾の到達までに動く先を狙います。到達時間は「距離 ÷ その間の平均の速さ」で見積もります(今の速さに、推力で増える分を足し、`MaxSpeed` で抑える)。
   見積もった時間だけ目標を動かした点で距離を測り直し、これを `PredictionIterations` 回(既定3回)繰り返します。回数が多いほど、動く目標に正確です。0なら目標の今の位置を狙います。
2. **重力の分を上乗せする。** 重力を受ける弾は、到達までに落ちる分だけ上を狙います。
3. **機首を先へ向ける。** 弾の速度は機首より遅れて曲がります。機首を迎撃点へ向けるだけでは、速度が追いつく前に目標の横や上を通り過ぎます。
   そこで、機首を「迎撃点への向き」より、速度の向きとのずれの分だけ先へ向けます。推力が速度の向きを迎撃点の方へ引き寄せます。
4. **トルクで回す。** トルクは機首と狙う向きのずれに比例し、`Gain` に比例した上限があります。実際の曲がりやすさは、`Gain`・弾の質量とコライダー(回しにくさ)・`AngularDrag`・安定翼 `Stability`・推力の大きさで決まります。
5. **揺らぎ。** 目標まで約70m以上離れている間は、ときどき短い揺らぎが入ります。

`Gain` が小さい誘導弾は、近距離で大きく曲がることはできません。遠くから撃つほど、修正する時間があります。

## 誘導の解除

| きっかけ | 内容 |
|---|---|
| 角度 | 機首と「弾から目標への向き」のなす角が `ReleaseAngle` を超えたとき。機首を軸にした円錐の半頂角で、90なら目標が前方の半球にいる限り追う。発射直後から判定するので、目標から大きく外れた向きに撃つと、すぐ無誘導になる。0なら角度では解除しない |
| 見失い | 目標が壊れた・リスポーンした・シミュレーションが終わった |

解除された弾は、別の目標を追い直しません。外れて目標を通り過ぎた弾が引き返すのを防ぐには、`ReleaseAngle` を90程度にします。

## 速さ

推力だけでは弾は加速し続けます。速さは次の組み合わせで決めます。

| 要素 | 働き |
|---|---|
| `Booster/Thrust` | 前へ押す力 [N]。加速度 = 推力 ÷ 弾の質量 |
| `Projectile/Drag` | 抗力。速さに比例して減速し、推力と釣り合う速さで頭打ちになる。加速も緩やかになる |
| `Booster/MaxSpeed` | 最高速度 [m/s]。この速さ以上の間は推力を出さない(重力や爆風で超えることはある) |
| `Booster/ThrustTime` | 推力を出す時間 [s]。燃料が切れると慣性で飛ぶ |

例: 推力1000N・質量5kg・`Drag` 0.9 なら、約220 m/s で頭打ちになります(Besiegeの物理の刻みは0.01秒)。

## 要素

`Projectile/Guidance`(C#では `ProjectileSpec.Guidance` = `GuidanceSpec`)の要素です。

| 要素 | 既定値 | 意味 |
|---|---|---|
| `Gain` | `0` | 誘導の強さ(旋回トルクの係数)。0なら誘導しない |
| `ReleaseAngle` | `0` | 解除角 [度]。0なら角度では解除しない |
| `PredictionIterations` | `3` | 迎撃点の予測の反復回数。0なら目標の今の位置を狙う |

全要素の正確な説明は [XMLリファレンス](../reference/xml-modules.md#ewlweapon-projectile-guidance) を見てください。

## 確かめ方

SPには敵がいないので、コンソールコマンドでテスト用の標的を置けます。

| コマンド | 内容 |
|---|---|
| `ewl_dummy add [距離]` | カメラの水平な前方、指定距離(既定150m)の地面に4mの箱を置く |
| `ewl_dummy clear` | 置いた標的を全部消す |

標的は、置いたピアでだけ敵として選ばれます。Besiegeのプレイヤーやマシンではなく、マルチプレイでは同期しません。弾は当たって爆発します。
