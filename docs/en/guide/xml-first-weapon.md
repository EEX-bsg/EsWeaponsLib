# Building Your First Weapon (XML)

Build a block that fires using XML alone, without writing any C#.

Prerequisites: You know how to make a Besiege mod (`Mod.xml`, block XML, resources), and EWL is installed.

## 1. Prepare the mod

It is the same as an ordinary mod. Since you are not using EWL's C#, `Assemblies` can stay empty.
Set `LoadOrder` to 1 or higher so that your mod loads after EWL ([Depending on EWL](concepts.md#depending-on-ewl)).

```xml
<Mod>
    <Name>My Weapons</Name>
    <Author>you</Author>
    <Version>0.1.0</Version>
    <Description>Weapons built on E'sWeaponsLib.</Description>
    <Debug>true</Debug>
    <MultiplayerCompatible>true</MultiplayerCompatible>
    <LoadOrder>1</LoadOrder>

    <Assemblies />
    <Blocks>
        <Block path="Blocks/MyGun.xml" />
    </Blocks>
    <Resources>
        <Mesh name="box" path="box.obj" />
        <Texture name="olive" path="olive.png" />
    </Resources>
    <!-- For the ID, use the value generated by Besiege's mod tools -->
</Mod>
```

## 2. Write EwlWeapon in the block

Write `EwlWeapon` in the block XML's `Modules`. `modid` is EWL's Mod ID.

```xml
<Block>
    <!-- Name, ID, Mesh, Colliders, etc. are the same as for an ordinary block -->

    <ModuleMapperTypes>
        <Key displayName="Fire" key="fire" default="C" />
    </ModuleMapperTypes>
    <Modules>
        <EwlWeapon modid="0d219960-b202-4906-b29d-8d90a61a89b8">
            <FireKey key="fire" />
            <MuzzlePosition x="0" y="0" z="1.3" />
            <MuzzleVelocity>150</MuzzleVelocity>
            <FireInterval>0.3</FireInterval>
            <Projectile>
                <Mass>0.5</Mass>
                <BlockDamage>1</BlockDamage>
            </Projectile>
        </EwlWeapon>
    </Modules>
</Block>
```

- Only `FireKey` is required. For `key`, write the `key` of a key defined in `ModuleMapperTypes`.
- Elements you do not write take their default values (muzzle velocity 100 m/s, interval 0.5 s, a small sphere projectile with mass 1, damage 0, unlimited ammo, and so on).
- `MuzzlePosition` is the block-local muzzle position. The projectile flies in the +Z direction of `MuzzleRotation` (by default, the front of the block).
  Place **the muzzle position outside the block's colliders**.

## 3. Try it

1. Launch Besiege, place the block, and start the simulation.
2. Press `C` to fire. Holding it down fires continuously (the default of `HoldToFire` is `true`).
3. If the block is pushed backward by the recoil, firing works.

With `Debug` set to `true`, just saving the XML while in the game applies many values from the next simulation.

## 4. Make it explode

Adding `Explosion` to the projectile makes it explode on impact. A projectile with a non-zero `Radius` is an exploding projectile.

```xml
<Projectile>
    <Mass>0.5</Mass>
    <Lifetime>8</Lifetime>
    <BlockDamage>1</BlockDamage>
    <EntityDamage>50</EntityDamage>
    <Explosion>
        <Radius>2</Radius>
        <Force>1500</Force>
        <UpwardsModifier>0.5</UpwardsModifier>
    </Explosion>
</Projectile>
```
