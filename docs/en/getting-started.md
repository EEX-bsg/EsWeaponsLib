# Getting Started (for Players)

E'sWeaponsLib (EWL) is a **prerequisite mod** used by weapon mods. Installing EWL alone does not add any blocks.
Install it together with a mod that uses EWL (such as E'sTankCannonsMod) when you play that mod.

## Installation

1. Subscribe to EWL and the mod that uses it (E'sTankCannonsMod, etc.) on the Steam Workshop.
2. Launch Besiege.
3. Open the Mods menu and enable both.

## Multiplayer

- The host and the participants must have the same mods installed (including EWL).
- EWL weapons are synchronized automatically. A player who joins midway cannot see projectiles fired before they joined (they will see the next projectiles).

## Troubleshooting

| Symptom | What to check |
|---|---|
| EWL does not work | Is EWL enabled? Did you restart Besiege after enabling EWL? |
| Only some EWL features are missing | Are both EWL and the mod that uses it up to date? |
| Multiplayer is out of sync | Does everyone have the same version of the mods? |

We recommend restarting Besiege first.  
If that does not fix it, report the problem to the author of the mod that uses EWL or to the EWL issue tracker, attaching `Besiege_Data/output_log.txt`.
